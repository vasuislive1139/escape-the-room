📋 Official Challenge Tasks (Preview)

Task 01 // Time Paradox
Find the oldest file in the entire project repository.
💡 Hint: Inspect file timestamps using terminal listing commands like ls -lt or recursive file search utilities.
Task 02 // Dependency Matrix
Find the source file with the highest number of module imports.
💡 Hint: Count occurrences of keyword import or require() using regex pattern matching tools across all JavaScript/TypeScript files.
Task 03 // Verbose Architecture
Find the UI component or class with the longest identifier name.
💡 Hint: Parse component declarations and sort identifier strings by character length.
